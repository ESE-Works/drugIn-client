# 계약 진단 플로우 프론트엔드 개발 프롬프트

> Claude Code / Cursor에 그대로 붙여넣어 사용

---

## 요구사항

직방 "지킴진단" 플로우를 벤치마킹한 **3단계 화면**을 구현한다.

```
Step 1  거래 유형 선택  →  Step 2  주소 입력  →  Step 3  진단 리포트
```

---

## Step 1 — 거래 유형 선택 예시

```
[상단 진행바 33%]
<                거래 유형 선택

거래 유형을
선택해주세요.

┌────────┐ ┌────────┐ ┌────────┐
│  전세   │ │  월세   │ │  매매   │
└────────┘ └────────┘ └────────┘

전세금
┌──────────────────────────────┐
│ 전세금을 입력해주세요.      만원 │
└──────────────────────────────┘

         [ 다음 ]
```

**동작**

- 거래 유형 카드 3개, 단일 선택. 선택 시 테두리 + 텍스트를 accent 색상으로 변경
- 선택한 유형에 따라 금액 필드 라벨과 개수 변경
  - `전세` → 전세금 1개
  - `월세` → 보증금 + 월세 2개
  - `매매` → 매매가 1개
- 금액 입력: 숫자만, 3자리 콤마 자동 포맷, 우측에 `만원` 고정 텍스트
- 모바일 숫자 키패드 강제 (`keyboardType="number-pad"`)
- `다음` 버튼: 유형 선택 + 금액 입력 완료 시에만 활성화 (비활성 시 연한 배경 + 흐린 텍스트)

**저장 데이터**

```ts
{
  dealType: 'lease' | 'monthly' | 'sale',
  deposit: number,              // 만원
  monthlyRent: number | null    // 월세 선택 시에만
}
```

## Step 2 — 주소 입력 예시

```
[상단 진행바 66%]
<                  주소입력

진단 받을 곳의 주소를
입력해주세요.

┌──────────────────────────────┐
│ 경기 광명시 서부샛길 778     🔍 │
└──────────────────────────────┘

┌──────────────────────────────┐
│ 가산디오스텔 오피스텔 502    ˅ │
└──────────────────────────────┘

┌──────────────────────────────┐
│ ⓘ 동·호 구분이 명확하지 않은     │
│   일반건물(다가구, 고시원 등)은  │
│   건물 기준으로 분석이 제공됩니다.│
└──────────────────────────────┘

         [ 확인 ]
```

**동작**

- 첫 번째 필드 탭 → 카카오 우편번호 서비스 모달 오픈
  - 웹: `react-daum-postcode`
  - 앱: WebView로 동일 서비스 임베드
- 주소 선택 완료 시 필드에 자동 입력
- 두 번째 필드: 동·호수 선택 드롭다운 (우측 `˅` 아이콘)
- 안내 박스: 회색 배경 + `ⓘ` 아이콘, radius 12
- `확인` 버튼: 도로명 주소 입력 완료 시 활성화

**저장 데이터**

```ts
{
  roadAddress: string,     // "경기 광명시 서부샛길 778"
  detailAddress: string,   // "가산디오스텔 오피스텔 502"
}
```

## Step 3 — 진단 리포트 예시

```
<              진단 리포트              ↑

경기 광명시 서부샛길 778 가산디오스텔
오피스텔 502                        🏠
전세 · 5,000만원

┌─────────────────────────────────┐
│      ✨ AI 종합 진단 의견          │
│                                 │
│  보증금 대비 기존 채무가 많아      │
│  보증금 보호 조치가 중요해요.      │
│  확인이 필요한 항목 중 2건은       │
│  제공해 드리는 특약으로 대비할     │
│  수 있어요.                      │
│                                 │

│                                 │
│  본 진단 리포트는 26.7.21 기준으로 │
│  발급되었습니다.                  │
└─────────────────────────────────┘
```

**동작**

- 상단 헤더: 주소 2줄 + 우측 집 일러스트, 아래 `거래유형 · 금액` 회색 텍스트
- 우상단 공유 버튼 (`↑` 아이콘) — OS 공유 시트 연동
- **AI 종합 진단 의견 카드**
  - 연한 배경(`#F3F5FD` 등), radius 16, 전체를 감싸는 컨테이너
  - 상단에 `✨ AI 종합 진단 의견` 뱃지 (파란 배경 + 흰 텍스트, radius 999)
  - 진단 문구는 중앙 정렬, 볼드, 텍스트에 하이라이트 배경
- **확인 필요 항목 카드** (흰 배경, 내부 카드)
  - 타이틀: `확인이 필요한 항목 N개가 있어요!` — N은 건수 합계
  - 각 행: `[이모지] [항목명]` ... `[건수] >` 형태, 건수는 밑줄 + 볼드
  - 건수가 없는 항목은 `바로 확인`으로 표시
  - 행 탭 시 상세 화면으로 이동
- **맞춤 특약 카드** (흰 배경, 내부 카드)
  - `✅ 안전한 계약을 위한 특약` ... `11개 >`
- **등기부등본 카드** (흰 배경, 내부 카드)
  - `📋 건물 등기부등본` ... `PDF 보기` — 탭 시 PDF 뷰어 오픈
- 최하단 발급일 캡션: 회색 12px, 중앙 정렬

**데이터 구조**

```ts
{
  address: { road: string; detail: string },
  dealType: string,
  amount: number,
  aiSummary: string,
  diagnosisItems: Array<{
    id: string,
    icon: string,
    label: string,
    count: number | null,   // null이면 "바로 확인" 표시
  }>,
  specialTerms: { count: number },
  registryPdfUrl: string,
  issuedAt: string,         // "26.7.21"
}
```

## 디자인 토큰

```ts
export const colors = {
  accent: '#00A896', // 브랜드 메인 (직방 오렌지 대신 자사 컬러)
  accentLight: '#E8FBF7',
  navy: '#1A2B4A',
  gray: '#667085',
  bgLight: '#F4F7F6',
  cardBg: '#F3F5FD', // AI 진단 카드 배경
  border: '#E4E9E7',
  white: '#FFFFFF',
};

export const radius = { sm: 8, md: 12, lg: 16, full: 999 };
export const spacing = { xs: 4, sm: 8, md: 16, lg: 24, xl: 32 };
```

**타이포그래피**

- 화면 제목: 26px / Bold / navy / line-height 1.35
- 카드 제목: 17px / Semibold / navy
- 본문: 14px / Regular / gray
- 캡션: 12px / Regular / gray

**공통 규칙**

- CTA 버튼: 높이 56px, radius `md`, 비활성 시 `accentLight` 배경 + 흐린 텍스트
- 입력 필드: 높이 56px, 테두리 1px `border`, 포커스 시 `accent` 테두리
- 상단 진행바: 높이 3px, 좌측부터 `accent` 색상으로 채움

## 재사용 컴포넌트

| 컴포넌트        | 용도                                            |
| --------------- | ----------------------------------------------- |
| `StepHeader`    | 뒤로가기 + 타이틀 + 진행바                      |
| `SelectCard`    | 거래 유형 선택 카드                             |
| `AmountInput`   | 금액 입력 (콤마 포맷 + 단위)                    |
| `PrimaryButton` | 하단 CTA (활성/비활성 상태)                     |
| `InfoBox`       | ⓘ 회색 안내 박스                                |
| `DiagnosisRow`  | 진단 항목 한 줄 (이모지 + 라벨 + 건수 + 화살표) |
| `ReportCard`    | 리포트 내부 흰색 카드 컨테이너                  |

## 예외 처리

| 상황                | 처리                                      |
| ------------------- | ----------------------------------------- |
| 금액 미입력         | 다음 버튼 비활성                          |
| 주소 미선택         | 확인 버튼 비활성                          |
| 상세 주소 없는 건물 | 안내 박스 문구 유지, 건물 기준 분석 진행  |
| 진단 데이터 로딩 중 | 리포트 화면 스켈레톤 UI                   |
| 진단 실패           | "리포트를 불러올 수 없어요" + 재시도 버튼 |
